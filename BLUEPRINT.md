## 1. What it is

A one-page dark portfolio for a software developer, IoT researcher & creative technologist. Black ground `#090909`, warm-white type `#f2efeb`, crimson accent `#ef4151`, film grain overlay, thin section rules, oversized red condensed lettering (`PORTFOLIO`) behind a cut-out portrait. Fonts: **Anton** (display), **Manrope** 400–800 (body), **Caveat** 400/500 (handwritten accent), loaded from Google Fonts by `index.html`.

Sections in order:
1. Sticky header (with live active nav tracking, Swarm Build trigger, and Motion toggle).
2. Hero (giant `PORTFOLIO` lettering, high-res cutout portrait, intro, metrics `20+`, `5+`, `11+`, CV download link).
3. Selected work (featured items, then the full interactive archive with category filters, search box, load more, modal project dialog with still/interactive stages, and the brand-logo strip).
4. Recognition & Awards (laurel wreath badge with `11+ VERIFIED CREDENTIALS`, list of 11 verified certifications from eDC IIT Delhi, HKCL, Oracle, Google, Microsoft, LinkedIn).
5. Breakdown (before/after interactive comparison slider with ESP32 schematic vs live hardware).
6. About (academic background, technical toolkit with software badges, 5-step engineering process, quote card).
7. Journey (experience accordion with active expand/collapse, milestone highlights).
8. Contact (direct links, masked phone number `+91 90506-XXXXX`, email, GitHub, LinkedIn, WhatsApp brief form).
9. Footer (copyright, wordmark, and back to top navigation).

Motion (all Framer Motion, inside `src/app.jsx`):
- Global easing `[0.22, 1, 0.36, 1]`
- Reveal-on-scroll `y 32 → 0`
- Scroll-linked hero parallax
- Magnetic buttons (`stiffness 220, damping 20`)
- Spring custom cursor (`CustomCursor` with dot & smooth trailing ring)
- Auto-scrolling brand rail
- Animated category filter underline with `layoutId`
- Project dialog spring-in with backdrop blur
- Header Motion toggle and `prefers-reduced-motion` support.

```javascript
async function download(item) {
  const destPath = path.resolve(item.dest);
  fs.mkdirSync(path.dirname(destPath), { recursive: true });
  const res = await fetch(item.url, { headers: { 'User-Agent': 'Mozilla/5.0' } });
  if (!res.ok) throw new Error(`Failed to download ${item.url}: ${res.status}`);
  const fileStream = fs.createWriteStream(destPath);
  await pipeline(Readable.fromWeb(res.body), fileStream);
  console.log(`✓ Downloaded: ${item.dest}`);
}

async function main() {
  console.log(`Downloading ${filesToDownload.length} assets from ${BASE_URL}...`);
  for (let i = 0; i < filesToDownload.length; i += 5) {
    const chunk = filesToDownload.slice(i, i + 5);
    await Promise.all(chunk.map(download));
  }
  console.log(`\nAll assets downloaded and verified locally!`);
}

main().catch(err => { console.error(err); process.exit(1); });
```

## 5. Verification Check Script (`scripts/check.mjs`)

```javascript
import fs from 'node:fs';
import path from 'node:path';
import { execSync } from 'node:child_process';

console.log('Running build check...');
execSync('node scripts/build.mjs', { stdio: 'inherit' });

const requiredFiles = [
  'index.html',
  'Asset/dist/app.js',
  'Asset/dist/app.css',
  'Asset/img/shikshanand-portrait.png',
  'Asset/img/favicon.svg',
  'Asset/cv/Shiksha_Nand_Resume.pdf',
  'Asset/img/certificates/shiksha_nand_cert.png',
  'Asset/img/certificates/hkcl_logo.png',
  'Asset/img/certificates/oracle_ai_cert.png',
  'Asset/img/certificates/coursera_cybersecurity_cert.png',
  'Asset/img/certificates/microsoft_genai_cert.png',
  'src/data/projects.json',
  'src/data/brands.json'
];

let allOk = true;
for (const file of requiredFiles) {
  const p = path.resolve(file);
  if (!fs.existsSync(p) || fs.statSync(p).size === 0) {
    console.error(`Missing or empty file: ${file}`);
    allOk = false;
  } else {
    console.log(`✓ ${file} (${fs.statSync(p).size} bytes)`);
  }
}

if (!allOk) process.exit(1);
console.log('\nAll checks passed!');
```
